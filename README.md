# BPC
BPC stands for, Bundle Pack Connection. My new library is built for Python. This library was also built of different libraries, to bundle it, into a pack. You are able to install this library with Git, or without Git. This project, uses the MIT License.

To install with Git, the installation, via

pip3 install git+https://github.com/upload-byte/BPC.git

and to install without Git, the installation, via

pip3 install https://github.com/upload-byte/BPC/archive/refs/heads/main.zip

to verify the installation was sucessful, output should be:

Successfully installed bpcl-0.1.0
